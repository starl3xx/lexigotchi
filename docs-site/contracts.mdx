Everything you own in Lexigotchi is a standard token in your own wallet, and every rule that moves value runs in a contract anyone can read.

## The chain

Lexigotchi runs on [Base](https://docs.base.org), an Ethereum layer 2.

Right now the game runs on **Base Sepolia** (chain ID 84532), Base’s test network, so its \$WORD is test \$WORD with no value. At launch it moves to **Base mainnet** (chain ID 8453). [Connect to Base](https://docs.base.org/base-chain/quickstart/connecting-to-base) lists both networks’ settings, and [Get Funds](https://docs.base.org/base-chain/network-information/network-faucets) lists faucets for Base Sepolia ETH, which pays testnet gas.

## Signatures and approvals

- **Listings** are free signatures, not transactions. Each one is a [Seaport 1.6](https://github.com/ProjectOpenSea/seaport) order, signed with [EIP-712](https://eips.ethereum.org/EIPS/eip-712). Seaport is the open-source exchange contract OpenSea uses, at [`0x0000…B395`](https://basescan.org/address/0x0000000000000068F116a894984e2DB1123eB395) on every chain. Seaport settles the sale when someone buys. A listing lasts 30 days.
- **Word sales**: one word for a price in \$WORD. The order pays 90% to the seller and 10% to the SaleFees contract, and the Market refuses any order that pays less. SaleFees sends the fee to the [Rewards Pool](/fees) each day.
- **Letter sales**: some of one letter, for a price in \$WORD each, with the same 90% and 10% on every letter. The order can be filled in parts (Seaport’s `PARTIAL_OPEN`), so a buyer takes any number of the letters. Every amount in it is a per-letter amount times the quantity, so any part of it is a whole amount.
- **Approvals.** The first time you sell letters, your wallet approves Seaport to move your letters. The first time you stake, it approves the Staking contract to hold your words. Each is a standard `setApprovalForAll` for that one collection. Selling a word approves Seaport for **that word only** (`approve`), and the approval ends when the word moves. Buying approves Seaport for exactly the price.
- **Signing in** for [your profile](/profile) is a [Sign-In with Ethereum](https://eips.ethereum.org/EIPS/eip-4361) message. It’s free and sends nothing onchain.
- **Coinbase verification** is an attestation on Base mainnet, made with the [Ethereum Attestation Service](https://docs.attest.org/). The game only reads it.

## How draws are decided

Packs, the daily letter, and rolls all work the same way. Your payment locks in the draw first. Then the game draws the result and signs it, and the contract checks that signature before it mints or raises anything. Minting also refuses any letter whose supply is used up. See [fairness](/fairness) for the jackpot.
